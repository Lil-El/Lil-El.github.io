# 组件类型提取

```ts [!title:src/components/number-scroller/type.ts]
import type { CSSProperties } from "vue";

export interface Vue3NumberScrollerProps {
  num?: number | string;
  duration?: number;
  height?: number;
  backStyle?: CSSProperties;
}

export interface DigitType {
  digit: number;
  initial: number;
  offset: number;
}
```

提取之后，在 `vue` 文件中导入使用；

## global 配置

[为全局组件注册提供类型支持，具体来说是​​为组件库的组件添加 `TypeScript` 类型声明​​，使其在 `Vue` 模板中能够获得类型检查和智能提示。](!notation:highlight:yellowgreen)

```ts [!title:global.d.ts]
import "vue";

declare module "vue" {
  export interface GlobalComponents {
    NumberScroller: typeof import("@lil-el/number-scroller")["NumberScroller"];
  }
}

```

## tsconfig 配置

`tsconfig` 需要对 `ts` 文件进行处理

```json [!title:tsconfig.xx.json]
{
  compilerOptions: {}, // ...
  "include": ["src/**/*.ts", "src/**/*.vue"],
}
```

具体可以查看[上一章](https://lil-el.github.io/#/blogs/5)

# `npm` 发布

将组件库进行打包，执行命令：

```bash
$ pnpm run build
```

将打包之后的文件 `dist/lib/es/global.d.ts` 在 `package.json` 的 `files` 字段进行设置。然后发布至 `npm`：

```bash
$ pnpm publish
```

# 安装使用

在新的项目下，执行命令

```bash
$ pnpm install @lil-el/my-ui
```

在 main.ts 中进行全局注册，当然也可以选择直接在文件中局部注册使用；

```ts [!title:main.ts]
import "style.css";

import "@lil-el/my-ui/es/base.css";
import "@lil-el/my-ui/es/components/number-scroller/index.css";

import { createApp } from "vue";
import App from "./App.vue";

import { Vue3NumberScroller } from "@lil-el/my-ui";

createApp(App).use(Vue3NumberScroller).mount("#app");
```
> 这里是在全局中，注册单个组件

```vue [!title:App.vue]
<NumberScroller :num='12.34' />
```

当我们输入 `:` 时，会自动提示组件所拥有的属性
