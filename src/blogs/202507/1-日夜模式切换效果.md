# 日夜模式切换涟漪效果实现 [!toc hide]

---

# 背景

在 [element-plus](https://element-plus.org/) 网站中，点击日夜模式切换时，有[从中心向外扩散](!notation:underline:greenyellow)的颜色的平滑过渡效果；

所以我们可以基于 `CSS 圆心渐变` 实现一下；

# 实现

## 核心

1. [通过 `radial-gradient` 实现圆形样式；](!notation:underline:red)
2. [需要在点击按钮时调整圆心的位置；](!notation:underline:red)
3. [使用`@property`实现 `background-image` 的动画过渡效果；](!notation:underline:red)

   ```markdown [!tip:primary]
   由于 `background-image` 的样式无法使用 `transition` 动画，所以只能使用 `@property` 实现动画效果；

   每次只需要调整 `--size` 的值，就可以实现动画效果；
   ```

## 代码

```html [!title:index.html]
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>light</title>
    <style>
      * {
        margin: 0;
        padding: 0;
      }
      @property --size {
        syntax: "<length>";
        initial-value: 0;
        inherits: false;
      }
      body {
        --size: 0px;
        width: 100vw;
        height: 100vh;
        background-repeat: no-repeat;
        transition: --size 0.8s ease-in;
      }
      .dark {
        --size: 2000px;
      }

      .btn {
        position: absolute;
        top: 10%;
        left: 90%;
        color: aqua;
        cursor: pointer;
      }
    </style>
  </head>
  <body>
    <div class="btn" onclick="toggle(event)">toggle</div>

    <script>
      function toggle(evt) {
        document.body.style.backgroundImage = `radial-gradient(circle at ${evt.clientX}px ${evt.clientY}px, white var(--size), black var(--size))`;
        document.body.classList.toggle("dark");
      }
    </script>
  </body>
</html>
```
